# Security policy

Report vulnerabilities privately to **justin@yumait.com.au**. Do not open a public issue for a vulnerability or include credentials, tenant data or personal details in a report.

Include the affected version, file or detection ID, impact, reproduction steps and a sanitised example. For approval or containment issues, explain which permissions and actions are involved. Coordinate disclosure with the maintainers while the report is investigated.

The latest release and the default branch are the supported versions. Older versions may receive fixes at the maintainers' discretion. There is no guaranteed response or fix timeframe.

This project has passed offline checks only. Validate it in a lab and review permissions, approval paths and recovery before use in a live environment. See [the validation limits](docs/validation.md).

The same private contact receives code of conduct reports.
